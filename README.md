# Personal Scripts & Utilities

A collection of personal scripts, automation tools, and workflows I've put together to handle various system maintenance tasks and utilities. These for the most part should be universally configurable (whether through variables in the script or config files) and purpose driven.

## Repository Structure

To keep things clean and organized, every script lives in its own dedicated, self-contained directory. Each folder houses its own files, configuration logic, and specific documentation.

## What's Inside

Since this is a catch-all repository for scripts I write, the tools inside handle a variety of personal use cases, including:

- Automating network share mounts (CIFS/SMB) using systemd user services.
- Staging, patching, and compiling updates for the `dwl` window manager.
- Managing automated encrypted backups using the Filen CLI.
- Miscellaneous utilities and workflow helpers that I add to over time.
